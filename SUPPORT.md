# Support

## Questions and deployment help

Use GitHub Discussions when enabled. Before posting, include:

- Keryx version or commit SHA;
- Node.js or Docker/Compose version;
- deployment shape, including reverse proxy;
- sanitized configuration values;
- exact error and reproduction steps.

Never post API tokens, production `.env` files, private URLs, downloaded Shortcuts, personal data, or unredacted proxy logs.

## Bugs

Use the bug report issue form. Only the latest `main` and the latest published release receive fixes during the pre-1.0 period.

## Security issues

Do not use Discussions or public issues. Follow [SECURITY.md](SECURITY.md).

## Commercial or guaranteed support

The open-source repository does not provide an SLA, guaranteed response time, or guaranteed compatibility with every proxy, AI client, or upstream application.
